## Contoh framework tambahan

Dua contoh di bawah menggunakan komponen native. Tidak termasuk hitungan 60 desain HTML.

- [React / Pulse](../frameworks/react/index.html): useState, useMemo, tabel, filter periode, ekspor CSV.
- [Vue / Rakit](../frameworks/vue/index.html): ref, computed, pencarian, keranjang, batas stok.

Jalankan melalui server HTTP. Library framework dimuat dari CDN.
