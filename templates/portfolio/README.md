# Portofolio

54 portofolio dalam sembilan kelompok profesi. Terdiri dari enam template lama
yang dipindahkan, 42 implementasi tambahan orisinal, dan enam adaptasi HTML dari
bagian kode upstream MIT.

## Kategori

- [Developer dan software engineer](developer/README.md): 8 model.
- [UI, UX, brand, dan desain grafis](design/README.md): 7 model.
- [Fotografi dan dokumenter](photography/README.md): 6 model.
- [Arsitektur, interior, dan produk](architecture/README.md): 6 model.
- [Film, musik, ilustrasi, dan seni](creative/README.md): 8 model.
- [Penulis, jurnalis, dan penerjemah](writing/README.md): 5 model.
- [Akademik, riset, dan data](research/README.md): 5 model.
- [Profesional, pengajar, dan kuliner](professional/README.md): 5 model.
- [Mahasiswa, lulusan, dan pelajar](student/README.md): 4 model.

Model berbeda mencakup terminal, CV, sidebar, casebook, contact sheet,
editorial, daftar publikasi, notebook, dan indeks jasa. Pilih model pada galeri
dengan kategori Portofolio, jenis profesi, dan asal kode.

Tambahan versi 1.4.0 memperkenalkan 18 model: runbook DevOps, dossier keamanan,
catatan riset UX, desain inklusif, light table, atlas lapangan, studi tapak,
potongan ruang, flash sheet, keramik, suntingan naskah, teks paralel,
geospasial, protokol penelitian, kegiatan belajar, menu, tugas akhir, dan jurnal
praktik.

Enam URL lama tetap tersedia sebagai halaman pengalihan ke folder baru. Pemetaan
terdapat pada `../../portfolio-redirects.json`.

[Sumber dan lisensi](../../docs/PORTFOLIO-SOURCES.md)

## File untuk pemeliharaan

Setiap template HTML mempunyai file CSS dengan nama sama dalam foldernya. Simpan
pasangan file tersebut ketika menyalin template. Interaksi bersama memakai
`../../assets/portfolio.js`, `runtime.js`, dan `core.js` melalui src. Lihat
[panduan pemeliharaan](../../docs/MAINTENANCE.md).
