# Katalog template

108 halaman HTML. Portofolio memiliki 54 model dalam sembilan kategori profesi.

Buka `index.html` untuk mencari, memfilter, menyimpan, dan melihat pratinjau.

## Dashboard

- [Pulse / Sales](../templates/dashboard/pulse-sales.html) Dashboard penjualan
  terang dengan metrik tipis, tren mingguan, dan transaksi dalam satu alur.
- [Runway / Finance](../templates/dashboard/runway-finance.html) Ruang finansial
  gelap dengan saldo dominan dan buku kas tanpa kartu bertumpuk.
- [Orchard / Analytics](../templates/dashboard/orchard-analytics.html) Analitik
  editorial dengan batang horizontal berskala dan rincian kanal terbuka.
- [Dispatch / Logistics](../templates/dashboard/dispatch-logistics.html)
  Dashboard rute dengan diagram wilayah sebagai fokus dan antrean kurir
  berdampingan.
- [Sprint / Projects](../templates/dashboard/sprint-projects.html) Papan proyek
  tiga tahap tanpa metrik dekoratif, dilengkapi perpindahan tugas.
- [Kelas / Education](../templates/dashboard/kelas-education.html) Kalender
  belajar horizontal dengan ruang persiapan dan satu fokus materi.
